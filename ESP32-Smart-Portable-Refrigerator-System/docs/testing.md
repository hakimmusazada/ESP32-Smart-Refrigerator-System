# Testing

## Verified

The prototype was assembled and run, and it was demonstrated working at WUF13 (May 2026). The following functions were confirmed to work:

- Temperature and humidity shown on the LCD
- Door detection, with the buzzer sounding after the door had been open for 20 s
- Cooling from the Peltier assembly
- Operation from both the SMPS and the battery

## Not measured

No quantitative data was recorded. The prototype is no longer available, so the following remain open:

- Cooling curve (time to reach a target temperature) and minimum temperature
- Temperature stability over long runs
- Power consumption and battery runtime
- DHT11 readings compared against a reference instrument
- Performance at different ambient temperatures
